    Example 9. Adding consecutive numbers.

    In Example 3 we looked at sums of consecutive integers. As we continue working, we may want to ask the question, can we write \(134\) as the sum of 4 consecutive integers? We can generalize this by referring to the first value with a variable name, say \(x\text{.}\) The next larger number would then be \(x+1\text{.}\) The third and fourth numbers would be \(x+2\) and \(x+3\) respectively. Our question, can then be expressed as
    \begin{equation*} x+(x+1)+(x+2)+(x+3)=134 \end{equation*}
    🔗

    (a)

    Write an equation to represent the question, is there a set of three consecutive numbers that add up to 45?
    🔗
    🔗

    (b)

    Write an expression that represents the product of two consecutive numbers.
    🔗
    🔗

    (c)

    Write an expression that represents the sum of four consecutive odd numbers.

    Write an expression that represents the sum of a number and its reciprocal.
