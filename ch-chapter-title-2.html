    Example 1. The Locker Problem.

    (a)

    There are 20 lockers in a hallway numbered 1 through 20. The lockers all start out closed. Twenty students numbered one through 20 are given the following instructions: Student 1 is instructed to go through and open every locker. Student 2 is instructed to start with locker 2 and close every second locker. Student 3 is instructed to start with locker 3 and change the status of every third locker, that is, open a closed locker and close an open locker. Student 4 is instructed to start with locker 4 and change the status of every fourth locker. Students 5 through 20 are given similar instructions; what lockers remain open after the 20th student has completed?

    Example 2. Sigma Function.

    In mathematics we can use function notation to describe rules. For example, the divisor function counts the number of divisors of a given number. We will use the Greek letter sigma \((\sigma)\) to denote this function. So, for example, we can write \(\sigma(6)=4,\) because the number of divisors of 6 is 4, that is 6 is divisible by the numbers 1, 2, 3, and 6.

    (c)

    The prime factorization of a number can be used to help us determine the value of our sigma function. Consider the prime factorization of the number 72 which is \(2^3\cdot3^2.\) If we wanted to list all of the factors of 72, we recognize that for any factor it can have either 0, 1, 2, or 3 factors of 2 and 0, 1, or 2 factors of 3. Therefore we see the factors of 72 are:
    🔗
    \(2^0\cdot3^0=1\) \(2^0\cdot3^1=3\) \(2^0\cdot3^2=9\)
    \(2^1\cdot3^0=2\) \(2^1\cdot3^1=6\) \(2^1\cdot3^2=18\)
    \(2^2\cdot3^0=4\) \(2^2\cdot3^1=12\) \(2^2\cdot3^2=36\)
    \(2^3\cdot3^0=8\) \(2^3\cdot3^1=24\) \(2^3\cdot3^2=72\)
    Listing out in this manner we see that given 4 different options for the factor 2 and 3 different options for the factor 3, there are \(4\cdot3=12\) different factors for 72, and thus \(\sigma(72)=12.\)
    🔗
