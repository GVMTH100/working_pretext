    1.

    Simplify the following expression using correct order of operations:
    \begin{equation*} \frac{3-7}{5-3}+3\cdot4+(2-7)^2 \end{equation*}
    🔗
    Solution.
    \begin{equation*} \frac{3-7}{5-3}+3\cdot4+(2-7)^2 \end{equation*}
    \begin{equation*} \frac{-4}{5-3}+3\cdot4+(2-7)^2 \end{equation*}
    \begin{equation*} \frac{-4}{2}+3\cdot4+(2-7)^2 \end{equation*}
    \begin{equation*} \frac{-4}{2}+3\cdot4+(-5)^2 \end{equation*}
    \begin{equation*} \frac{-4}{2}+3\cdot4+25 \end{equation*}
    \begin{equation*} -2+3\cdot4+25 \end{equation*}
    \begin{equation*} -2+12+25 \end{equation*}
    \begin{equation*} 10+25 \end{equation*}
    \begin{equation*} 35 \end{equation*}
    🔗
    🔗
    🔗

    2.

    Simplify the following expression using correct order of operations:
    \begin{equation*} 3\sqrt{4\cdot5-(3+1)}-5(2-7)+4\div2^2-7 \end{equation*}
    🔗
    Solution.
    \begin{equation*} 3\sqrt{4\cdot5-4}-5(2-7)+4\div2^2-7 \end{equation*}
    \begin{equation*} 3\sqrt{20-4}-5(2-7)+4\div2^2-7 \end{equation*}
    \begin{equation*} 3\sqrt{16}-5(2-7)+4\div2^2-7 \end{equation*}
    \begin{equation*} 3\sqrt{16}-5(-5)+4\div2^2-7 \end{equation*}
    \begin{equation*} 3\cdot4-5(-5)+4\div2^2-7 \end{equation*}
    \begin{equation*} 3\cdot4-5(-5)+4\div4-7 \end{equation*}
    \begin{equation*} 12-5(-5)+4\div4-7 \end{equation*}
    \begin{equation*} 12+25+4\div4-7 \end{equation*}
    \begin{equation*} 12+25+1-7 \end{equation*}
    \begin{equation*} 27+1-7 \end{equation*}
    \begin{equation*} 28-7 \end{equation*}
    \begin{equation*} 21 \end{equation*}
    🔗
    🔗
    🔗

    3.

    Simplify the following expression using correct order of operations:
    \begin{equation*} 3^{\sqrt{4}}\div(3-2\cdot8)+4-2\cdot\frac{2-1}{9-4} \end{equation*}
    🔗
    Solution.
    \begin{equation*} 3^{\sqrt{4}}\div(3-16)+4-2\cdot\frac{2-1}{9-4} \end{equation*}
    \begin{equation*} 3^{\sqrt{4}}\div(-13)+4-2\cdot\frac{2-1}{9-4} \end{equation*}
    \begin{equation*} 3^{\sqrt{4}}\div(-13)+4-2\cdot\frac{1}{9-4} \end{equation*}
    \begin{equation*} 3^{\sqrt{4}}\div(-13)+4-2\cdot\frac{1}{5} \end{equation*}
    \begin{equation*} 3^{2}\div(-13)+4-2\cdot\frac{1}{5} \end{equation*}
    \begin{equation*} 9\div(-13)+4-2\cdot\frac{1}{5} \end{equation*}
    \begin{equation*} -\frac{9}{13}+4-2\cdot\frac{1}{5} \end{equation*}
    \begin{equation*} -\frac{9}{13}+4-\frac{2}{5} \end{equation*}
    \begin{equation*} -\frac{9}{13}+\frac{52}{13}-\frac{2}{5} \end{equation*}
    \begin{equation*} \frac{43}{13}-\frac{2}{5} \end{equation*}
    \begin{equation*} \frac{215}{65}-\frac{26}{65} \end{equation*}
    \begin{equation*} \frac{189}{65} \end{equation*}

    4.

    Simplify the following expression using correct order of operations:
    \begin{equation*} 4\cdot4-4\div4+4^{(4-4)}+(4+4)\div4 \end{equation*}
    🔗
    Solution.
    \begin{equation*} 4\cdot4-4\div4+4^{0}+(4+4)\div4 \end{equation*}
    \begin{equation*} 4\cdot4-4\div4+4^{0}+8\div4 \end{equation*}
    \begin{equation*} 4\cdot4-4\div4+1+8\div4 \end{equation*}
    \begin{equation*} 16-4\div4+1+8\div4 \end{equation*}
    \begin{equation*} 16-1+1+8\div4 \end{equation*}
    \begin{equation*} 16-1+1+2 \end{equation*}
    \begin{equation*} 15+1+2 \end{equation*}
    \begin{equation*} 16+2 \end{equation*}
    \begin{equation*} 18 \end{equation*}

    5.

    \begin{equation*} 3-4^{\frac{1}{2}}\cdot(4)^2\div(8-12) \end{equation*}
    \begin{equation*} 3-4^{\frac{1}{2}}\cdot(4)^2\div(-4) \end{equation*}
    \begin{equation*} 3-2\cdot(4)^2\div(-4) \end{equation*}
    \begin{equation*} 3-2\cdot16\div(-4) \end{equation*}
    \begin{equation*} 3-32\div(-4) \end{equation*}

    \begin{equation*} \frac{45}{5}+\frac{3}{5}+1-\frac{32}{3} \end{equation*}
    \begin{equation*} \frac{48}{5}+1-\frac{32}{3} \end{equation*}
    \begin{equation*} \frac{48}{5}+\frac{5}{5}-\frac{32}{3} \end{equation*}
    \begin{equation*} \frac{53}{5}-\frac{32}{3} \end{equation*}
    \begin{equation*} \frac{159}{15}-\frac{160}{15} \end{equation*}

    7.

    Consider the visual pattern shown below. Describe the pattern and draw the next step.

    Solution.
